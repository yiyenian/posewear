## 二、已完成的核心改造

### 1. Vercel 移植
- `api/proxy.js`:Edge Function 版转发代理(白名单/限流/拒内网)
- `vercel.json`:响应头(CSP 已放行 `http://127.0.0.1:* http://localhost:*`)
- lite 构建:`POSEWEAR_LITE=1`(398MB;过 5000 文件限制用 `--archive=tgz`)
- Windows 兼容:build.py 改线程池(ProcessPool 在 Windows spawn 会重跑脚本)

### 2. 本地 ComfyUI 服务商(与 OpenAI/Gemini/豆包/中转并存)
- 设置面板:粘贴 API 格式工作流 + 节点号,自动识别;无需 Key;测试连接走 `/system_stats`
- 节点号:**人物 40 / 服装 41 / 姿势 48 / 提示词 4 / 出图尺寸 6**
- 完整链路:参考图唯一文件名上传(`posewear-ref-N.jpg`)→ 填节点 → 提交 → 轮询 → 取图;seed 每次随机;节点级错误提示
- **提示词组装器 `composeC()`(核心)**:ComfyUI 模式不用原枚举式提示词,改为纯"目标画面描述"(库内人物描述注入 + 服装/姿势/画面),不含任何"参考图/第X张/试穿/线稿"字样及否定式描述 —— 实验证实这是消除拼贴、保住人脸一致的关键;手动编辑过提示词则走正则清理路径
- 身份锚定:人物选自人像库时自动注入库内描述(已剥离"正面半身肖像"等拍摄方式短语,避免大脸构图)

### 3. 我的面孔系统(浏览器 IndexedDB `posewear-faces`)
- 裁切工具:拖动/滚轮/滑杆;铺满裁切 / 完整放入;统一输出 **1080×1350**(与人像库一致);多张排队
- 统一背景(默认开):四角采样去底 → 换库风格浅色棚拍背景;背景复杂自动跳过
- 人物描述构建:发色自动识别(黑色/深棕/棕/金黄/浅色)+ 特征标签(性别/年龄/发型/眼镜/刘海)→ 中英双语描述 → 出图身份锚定与库内同级
- 命名:裁切时填写;已添加的在**大图预览 → ✎ 重命名面孔**
- 删除:卡片悬停 ✕(自定义=真删,内置人像=隐藏,`localStorage.hideF` 可恢复)
- 旧面孔(面孔 1-3)是占位描述 → 建议删除重加

### 4. 尺寸与体型
- 画幅 15 预设:标准档(960×1440、1024×1360、1024×1280、896×1600、1152²、1360×1024、1344×896、1600×896、1664×720)+ 高清档(1152×1728、1216×1632、1088×1920、1408²、1728×1152、1920×1088);全部 16 倍数
- 自定义尺寸:设置里填 `896x1600` 格式,优先于画幅
- 身高体型标签(纤细/高挑/丰满…):仅"没有照片"模式,写入人物描述
